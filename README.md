# 小雅课件下载 · Edge 扩展

一个本地运行的 Microsoft Edge 扩展，用于整理并下载小雅课程页面中当前账号有权访问的资源。下载文件由浏览器直接写入你选择的本地文件夹。

## 适用范围

- 适用于小雅教育平台的课程页面：`https://*.ai-augmented.com/`。
- 面向 Microsoft Edge Chromium 扩展，最低 Chromium 版本为 110。
- 使用你当前 Edge 配置文件中的小雅登录状态；扩展不会替你登录，也不会绕过课程权限、验证码或付费限制。
- 不适用于其他网课平台或普通网页下载。

## 可以做什么

- 自动列出已打开的小雅课程页，并按课程、章节和子文件夹显示资源。
- 下载平台提供的 PPT、PDF、文档、表格、图片和其他附件原件。
- 下载有播放授权的点播视频，包括 HLS 播放列表和直接视频文件；文件按源格式保存，不转码。
- 将作业题目与选项保存为可离线查看的 HTML。已打开的作答页可导出页面上可见的答案与成绩。
- 保存讨论主题与说明；不会导出同学发言或评论。
- 按“课程名 / 章节 / 子文件夹 / 文件名”保存，重名文件自动加序号，不覆盖现有文件。

直播、需要独立音轨的视频，以及小雅未提供可下载播放地址的资源暂不支持。作业导出只读取页面或平台接口已提供的内容，不会开始、提交或修改作业。

## 安装

推荐从 [GitHub 最新版本](https://github.com/iamcndl/xiaoya-course-downloader-edge/releases/latest) 下载 `xiaoya-course-downloader-edge-v1.3.7.zip`：

1. 解压压缩包。
2. 在 Edge 地址栏打开 `edge://extensions`。
3. 打开“开发人员模式”，选择“加载解压缩的扩展”。
4. 选中解压目录中的 `小雅课件下载` 文件夹（里面应能看到 `manifest.json`）。

之后按[使用教程](docs/使用教程.md)操作。扩展不需要 Python、Node、油猴或用户脚本管理器。

## 隐私与权限

- 扩展没有遥测、统计或自动上传功能，不使用 `chrome.storage`、`localStorage` 或 `sessionStorage` 保存课程数据、答卷、令牌或下载位置。
- 小雅登录令牌只在当前小雅页面上下文中用于同源接口请求；资源清单只返回必要字段。媒体下载请求不携带小雅 Cookie 或 Referer。
- 课程、资源和答卷内容只在扩展页面运行期间处理。下载文件只写入你亲自选择的本地目录。
- 为兼容不同课程使用的媒体 CDN，扩展声明了可选 HTTPS 主机权限。实际运行时只针对所选资源显示并请求具体域名；下载结束或等待额外授权时，会撤销本轮新授予的域名权限。
- 媒体服务器会收到正常下载请求和你的网络 IP。跨域重定向由浏览器跟进，扩展会核对最终域名后再读取响应内容。
- 下载报告只在你点击“导出下载报告”时生成在本地，可能包含课程名、资源名、章节、相对保存路径和下载状态。分享前请检查报告内容。
- 答卷文件可能含你的答案和成绩；它只会在你读取已打开的答卷页并选择下载后写入所选目录。

## 构建与检查

需要 Node.js 18 或更新版本：

```powershell
npm ci
npm test
npm run build
```

`npm test` 运行自动化测试；`npm run build` 会检查扩展发布文件白名单，并在 `dist/` 生成 Edge 安装包和商店提交包。用户只需 Edge 和安装包，不需要安装 Node.js。

## 项目文件

- `extension/`：可直接加载的扩展文件。
- `docs/使用教程.md`：面向使用者的逐步操作说明。
- `docs/安装与使用.txt`：简版安装说明。
- `tests/`：课程识别、资源解析、下载与内容转义测试。
- `scripts/build.mjs`：白名单构建脚本。

接口流程参考了 MIT 许可项目 [XiaoyaDownloader](https://github.com/zygame1314/XiaoyaDownloader)。扩展及依赖的第三方许可文本见 `extension/licenses/`。
