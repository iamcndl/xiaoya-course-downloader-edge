# 小雅课件下载 Edge 扩展 v1.3.7

## 本版本内容

- 按课程名、章节和子文件夹读取小雅资源，并按相同层级保存到用户选择的本地目录。
- 下载当前账号有权访问的普通附件，以及平台提供有效播放地址的 HLS 点播和直接视频文件。
- 保存作业题目与选项；从已打开的答卷页导出页面可见的个人答案和成绩。
- 保存讨论主题与说明，不导出其他人的发言或评论。
- 支持按类型和关键词筛选、单项勾选、全选当前结果和取消全选视频。
- 对媒体域名按需请求权限，流式保存视频，并在普通文件保存失败时清理不完整文件。

## 安装

下载本发布页的 `小雅课件下载-Edge-v1.3.7.zip`，解压后在 Edge 打开 `edge://extensions`，启用“开发人员模式”，选择“加载解压缩的扩展”，并选中包含 `manifest.json` 的“小雅课件下载”目录。详细步骤见 [使用教程](https://github.com/iamcndl/xiaoya-course-downloader-edge/blob/main/docs/%E4%BD%BF%E7%94%A8%E6%95%99%E7%A8%8B.md)。

## 支持范围与限制

此扩展仅适用于 `https://*.ai-augmented.com/` 下的小雅课程页面。它使用当前 Edge 配置文件中的小雅登录状态，不绕过登录、验证码、课程权限或付费限制。直播、需要独立音轨的视频，以及平台没有提供有效播放地址的资源暂不支持。

扩展不自动上传课程内容、答卷或下载报告。媒体请求不携带小雅 Cookie 或 Referer，但媒体服务器会收到普通请求和网络 IP。答卷导出可能包含个人答案与成绩；下载报告可能包含课程名、资源名和章节路径，分享前请检查内容。
