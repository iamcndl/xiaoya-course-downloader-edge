# 小雅课件下载使用教程

## 一、安装扩展

1. 打开项目的 [GitHub 最新版本页面](https://github.com/iamcndl/xiaoya-course-downloader-edge/releases/latest)，下载 `小雅课件下载-Edge-v1.3.7.zip`。
2. 在 Windows 资源管理器中解压压缩包。
3. 打开 Microsoft Edge，在地址栏输入 `edge://extensions` 并回车。
4. 打开左侧的“开发人员模式”。
5. 点击“加载解压缩的扩展”，选择解压目录里的 `小雅课件下载` 文件夹。确认所选文件夹内有 `manifest.json`。
6. 如需频繁使用，可在 Edge 的扩展菜单中固定“小雅课件下载”。

## 二、读取课程

1. 在 Edge 登录小雅，并进入要整理的课程页面。
2. 点击工具栏上的“小雅课件下载”图标。
3. 扩展会列出当前打开的小雅课程页。下拉列表显示课程名及所在章节路径；选择目标页面后点击“读取课件”。
4. 资源列表按章节和文件夹分组。可以输入关键词、筛选资源类型，逐项勾选要保存的文件。
5. “全选当前结果”会选中当前筛选结果；“取消全选视频”只取消视频勾选，不影响已选的其他文件；“清空选择”会取消所有勾选。

## 三、选择目录并下载

1. 点击“选择文件夹”，选定本机保存位置并允许写入。
2. 默认勾选“保留课程与章节目录”。下载结果会按 `课程名/章节/子文件夹/文件名` 整理。取消该选项时，课程根目录仍保留，文件不再按章节分层。
3. 勾选资源后点击“准备下载”。扩展会从小雅获取已授权的资源地址并检查文件。
4. 点击“开始下载”。Edge 可能询问是否允许访问某个媒体域名；核对提示中的域名后再决定是否允许。播放列表引用了其他域名时，扩展会再次说明并请求权限。
5. 下载期间保持扩展页面打开。完成后可以重试失败项，或选择导出下载报告。

同名文件会自动增加序号，例如 `讲义 (2).pdf`，不会覆盖已存在文件。

## 四、视频下载提示

- 点播视频需要小雅返回有效播放授权。若扩展提示已授权但没有播放地址，请回到小雅打开对应视频，等待播放器出现画面，再回扩展重新准备下载。
- 扩展支持平台提供的 HLS 点播和直接视频文件，不进行转码。直播、需要独立音轨的视频或平台未开放下载地址的资源暂不支持。
- 服务器跳转到新的媒体域名时，扩展会核对最终域名并申请相应权限。媒体服务器会收到正常下载请求和你的网络 IP；请求不带小雅 Cookie 或 Referer。

## 五、作业与讨论

- 课程中的作业节点可导出题目和选项。
- 如需保存自己的答案和成绩，先在小雅打开已提交的作业结果页，再在扩展课程列表中选择带有“答卷”的页面并读取。只会导出该页面可见的答案和成绩。
- 扩展不会开始、提交或修改作业，也不会读取页面未显示的答案解析。
- 讨论资源保存主题标题与平台提供的说明，不包含同学发言和评论。

## 六、报告与隐私

扩展不会自动上传课程文件、答卷或报告。登录令牌只在小雅页面上下文中用于同源接口请求，不保存在扩展存储中，也不随媒体下载请求发送。媒体服务器仍会看到普通网络请求所需的网络 IP。

下载报告由你点击按钮后才在本地生成，可能包含课程名、资源名、章节路径、相对保存路径和下载状态。把报告发给别人前，请检查是否需要删除这些课程信息。答卷文件可能含个人答案和成绩，请妥善保管。

## 七、常见问题

**课程列表为空**

确认已在同一个 Edge 配置文件登录小雅，并打开课程资源页；然后回扩展点击“刷新课程”。

**资源列表为空或读取失败**

确认当前账号能在小雅页面正常访问课程，刷新小雅课程页后重新读取。扩展不会绕过课程权限或访问限制。

**域名权限被拒绝**

下载需要访问小雅返回的媒体主机。查看 Edge 提示中的域名，只对你确认与当前课程资源相关的域名授予权限；之后可以重新点击“开始下载”。

**下载中断或出现失败项**

保持扩展页面打开，检查网络与媒体域名权限，再点击“重试失败文件”。损坏或不完整的临时文件会在失败时清理。

**如何更新扩展**

下载并解压新版本，在 `edge://extensions` 中重新加载更新后的扩展目录。若浏览器把新目录显示为另一个开发者模式扩展，移除旧副本后加载新目录。

## 支持范围

本扩展只支持 `https://*.ai-augmented.com/` 下的小雅课程页面。它只下载当前账号有权访问且平台返回有效地址的资源，不绕过登录、验证码、课程权限或付费限制。
